口徑（見網頁下方附註）：週出席年值為年平均每週出席，2026 年僅計第 1–43 週（第 44 週未結算已排除）；家聚會＝受訪＋出訪；受浸：2023–2025 年為全年合計，2026 年僅 1–10 月；2023–2024 年取自 Drive「2-青年得一萬」總表（2023年1-12月總表240107、2024年1-12月總表250101），台北、新北照顧區 2023–2026 年皆有 Drive 總表單獨數字（2025年1月與10月缺總表以推估，2026年僅至8月），圖上直接連接；高屏澎含高雄市、基宜花東為基宜＋花東合併，皆以總表合併列為準，各區合計與全台一致。時間範圍切換：全年／1-X 月（X 為上個月），1-X 月下週出席以 ISO 週週四歸月累計平均（1-9 月每年皆 39 週），受浸以 Drive 月總表累計，缺月（2023 年 1、2、4、6、7、8 月，2024 年 1、2、3、5 月）按時間比例推估並標示，月總表以表頭月份為準。
